# Task Router

## Purpose
Use this router to select the right AI Engineer Pack resources for a request.

## Routing Steps
1. Identify the primary task verb.
2. Select the matching command from [commands](../commands/README.md).
3. Identify the domain and select skills from [skills](../skills/README.md).
4. Choose a framework from [frameworks](../frameworks/README.md).
5. Use a template from [templates](../templates/README.md) if creating a new artifact.
6. Validate with checklists from [checklists](../checklists/README.md).
