# Security Review Skill

## Purpose
The Security Review skill supports threats, sensitive data, access control, secrets, dependency risk, input validation, and abuse cases. It gives AI assistants concrete guidance for planning, implementation, review, debugging, and documentation in this technology area.

## Contents
- [SKILL.md](SKILL.md): capability boundaries and expected outputs.
- [WORKFLOW.md](WORKFLOW.md): technology-specific execution process.
- [PROMPTS.md](PROMPTS.md): reusable prompts for Security Review work.
- [CHECKLIST.md](CHECKLIST.md): verification and quality checks.
- [EXAMPLES.md](EXAMPLES.md): practical scenarios and outputs.

## Usage
Use this skill when a task specifically involves Security Review decisions, files, tools, runtime behavior, or failure modes. Combine it with the parent [category skill](../README.md), relevant [commands](../../../commands/README.md), and [frameworks](../../../frameworks/README.md).
