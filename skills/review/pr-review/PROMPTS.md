# Pull Request Review Prompts

## Build
Use the Pull Request Review skill. Inspect existing project conventions, implement the requested change using idiomatic Pull Request Review patterns, verify with CI review, diff review, acceptance criteria checks, documentation review, and release risk review, and summarize changed files and risks.

## Review
Use the Pull Request Review skill. Review the change for correctness, maintainability, security, performance, and Pull Request Review-specific pitfalls such as approving without reading related code, ignoring failing checks, scope creep, and no rollback thinking. Provide findings by severity.

## Debug
Use the Pull Request Review skill. Reproduce or reason through the issue, inspect relevant files and runtime signals, identify the likely cause, apply a focused fix if requested, and verify with CI review, diff review, acceptance criteria checks, documentation review, and release risk review.

## Document
Use the Pull Request Review skill. Create documentation that explains setup, usage, configuration, limitations, and troubleshooting for this repository's Pull Request Review implementation.
