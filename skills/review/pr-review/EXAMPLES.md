# Pull Request Review Examples

## Implementation example
Request: Use the Pull Request Review skill to add a small feature in the current repository, follow existing conventions, and verify with CI review, diff review, acceptance criteria checks, documentation review, and release risk review.

Expected output: A focused implementation summary, changed files, verification results, and notes about Pull Request Review-specific risks.

## Review example
Request: Use the Pull Request Review skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as approving without reading related code, ignoring failing checks, scope creep, and no rollback thinking.

## Debugging example
Request: Use the Pull Request Review skill to investigate a failure involving PR scope, changed files, linked issues, CI status, reviewer guidance, rollout risk, and merge readiness.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
