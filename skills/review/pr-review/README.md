# Pull Request Review Skill

## Purpose
The Pull Request Review skill supports PR scope, changed files, linked issues, CI status, reviewer guidance, rollout risk, and merge readiness. It gives AI assistants concrete guidance for planning, implementation, review, debugging, and documentation in this technology area.

- [EXAMPLES.md](EXAMPLES.md): practical scenarios and outputs.
