# Review Skill

## Purpose
The $cat skill helps AI assistants plan, implement, review, document, and troubleshoot review work with clear scope and verifiable outcomes.

## Contents
- [SKILL.md](SKILL.md): capability definition, scope, inputs, and outputs.
- [WORKFLOW.md](WORKFLOW.md): step-by-step execution process.
- [PROMPTS.md](PROMPTS.md): reusable prompts for planning, implementation, review, and debugging.
- [CHECKLIST.md](CHECKLIST.md): quality gates before completion.
- [EXAMPLES.md](EXAMPLES.md): practical usage examples.

## Usage
Use this skill when a request depends on review knowledge, implementation decisions, review criteria, or troubleshooting. Pair it with [commands](../../commands/README.md), [frameworks](../../frameworks/README.md), and [checklists](../../checklists/README.md).
