# Code Review Prompts

## Build
Use the Code Review skill. Inspect existing project conventions, implement the requested change using idiomatic Code Review patterns, verify with diff inspection, requirement comparison, targeted test review, and severity-ranked findings, and summarize changed files and risks.

## Review
Use the Code Review skill. Review the change for correctness, maintainability, security, performance, and Code Review-specific pitfalls such as style-only reviews, vague comments, missed edge cases, no line references, and ignoring tests. Provide findings by severity.

## Debug
Use the Code Review skill. Reproduce or reason through the issue, inspect relevant files and runtime signals, identify the likely cause, apply a focused fix if requested, and verify with diff inspection, requirement comparison, targeted test review, and severity-ranked findings.

## Document
Use the Code Review skill. Create documentation that explains setup, usage, configuration, limitations, and troubleshooting for this repository's Code Review implementation.
