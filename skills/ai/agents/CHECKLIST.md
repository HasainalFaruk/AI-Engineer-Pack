# AI Agents Checklist

- [ ] The affected AI Agents files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids overpowered tools, vague goals, hidden state reliance, runaway loops, and missing human confirmation for risky actions.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes tool permission tests, trace review, scenario evals, handoff checks, and termination criteria.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
