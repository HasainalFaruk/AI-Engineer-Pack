# AI Agents Skill Definition

## Capability
Use this skill for agent instructions, tool routing, memory boundaries, handoffs, guardrails, and task completion loops. The assistant should inspect local conventions first, choose technology-appropriate patterns, and verify results with tool permission tests, trace review, scenario evals, handoff checks, and termination criteria.

## Best for
- Designing or modifying AI Agents-specific code, configuration, documentation, or tests.
- Reviewing implementation risks and maintainability concerns.
- Debugging failures that depend on AI Agents tooling or runtime behavior.
- Creating prompts or workflows that require accurate AI Agents terminology.

## Inputs
- User goal, acceptance criteria, and affected environment.
- Relevant source files, config files, dependencies, logs, or test output.
- Version constraints and deployment context.
- Security, performance, accessibility, reliability, or maintenance requirements.

## Outputs
- Focused plan, implementation, review, or debugging guidance.
- Technology-specific risks, tradeoffs, and verification steps.
- Updated docs or examples when behavior or usage changes.

## Watch for
Avoid overpowered tools, vague goals, hidden state reliance, runaway loops, and missing human confirmation for risky actions.
