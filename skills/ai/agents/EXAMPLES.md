# AI Agents Examples

## Implementation example
Request: Use the AI Agents skill to add a small feature in the current repository, follow existing conventions, and verify with tool permission tests, trace review, scenario evals, handoff checks, and termination criteria.

Expected output: A focused implementation summary, changed files, verification results, and notes about AI Agents-specific risks.

## Review example
Request: Use the AI Agents skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as overpowered tools, vague goals, hidden state reliance, runaway loops, and missing human confirmation for risky actions.

## Debugging example
Request: Use the AI Agents skill to investigate a failure involving agent instructions, tool routing, memory boundaries, handoffs, guardrails, and task completion loops.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
