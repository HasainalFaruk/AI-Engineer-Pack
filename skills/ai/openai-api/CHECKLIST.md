# OpenAI API Checklist

- [ ] The affected OpenAI API files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids unbounded prompts, missing evals, fragile JSON parsing, tool-call ambiguity, and no fallback behavior.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes schema validation, eval sets, prompt regression tests, token and latency checks, and failure-mode tests.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
