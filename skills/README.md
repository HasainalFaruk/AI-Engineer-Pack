# Skills

## Purpose
The `skills` folder contains domain-specific and technology-specific playbooks for AI-assisted engineering work. Category folders describe broad areas of practice, and technology subfolders provide concrete guidance for specific languages, frameworks, platforms, tools, and workflows.

## Contents
- [Languages](languages/README.md): programming language skills such as Python, TypeScript, and Java.
- [Web](web/README.md): web application skills such as React, Next.js, and WordPress.
- [CMS](cms/README.md): content management systems such as Drupal, Shopify, and Strapi.
- [Database](database/README.md): data stores such as PostgreSQL, MongoDB, and Redis.
- [DevOps](devops/README.md): delivery and operations tools such as Docker, Kubernetes, and GitHub Actions.
- [Cloud](cloud/README.md): cloud platforms such as AWS, Azure, and Google Cloud.
- [AI](ai/README.md): AI engineering skills such as OpenAI API, agents, and RAG.
- [Machine Learning](machine-learning/README.md): ML skills such as scikit-learn, PyTorch, and MLOps.
- [Security](security/README.md): security skills such as OWASP, authentication, and secrets management.
- [Embedded](embedded/README.md): embedded skills such as Arduino, ESP32, and PlatformIO.
- [Mobile](mobile/README.md): mobile skills such as React Native, Flutter, and Swift iOS.
- [Architecture](architecture/README.md): architecture skills such as microservices, event-driven design, and domain-driven design.
- [Testing](testing/README.md): testing skills such as pytest, Jest, and Playwright.
- [Documentation](documentation/README.md): documentation skills such as Markdown, OpenAPI, and ADRs.
- [Review](review/README.md): review skills such as code review, pull request review, and security review.
- [Debugging](debugging/README.md): debugging skills such as browser DevTools, Node.js debugging, and production debugging.

Each technology folder contains `README.md`, `SKILL.md`, `WORKFLOW.md`, `PROMPTS.md`, `CHECKLIST.md`, and `EXAMPLES.md`.

## Usage
Start with the category that matches the user's task, then choose the technology subfolder that best matches the files, tools, or runtime involved. Combine a technology skill with a [command](../commands/README.md), a [framework](../frameworks/README.md), and a [checklist](../checklists/README.md) for complete execution.
