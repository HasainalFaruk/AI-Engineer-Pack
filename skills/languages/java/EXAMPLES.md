# Java Examples

## Implementation example
Request: Use the Java skill to add a small feature in the current repository, follow existing conventions, and verify with unit tests, integration tests, static analysis, build lifecycle checks, and JVM runtime smoke tests.

Expected output: A focused implementation summary, changed files, verification results, and notes about Java-specific risks.

## Review example
Request: Use the Java skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as over-abstracted class hierarchies, unchecked nulls, blocking calls in async paths, and untested serialization.

## Debugging example
Request: Use the Java skill to investigate a failure involving JVM services, Spring-style applications, Maven or Gradle builds, concurrency, and typed domain models.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
