# Python Checklist

- [ ] The affected Python files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids global environments, unpinned dependencies, hidden mutable defaults, broad exception handlers.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes pytest, type checks, linting, import checks, and focused command-line smoke tests.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
