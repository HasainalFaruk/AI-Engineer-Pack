# TypeScript Checklist

- [ ] The affected TypeScript files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids any types, unsafe casts, mismatched runtime validation, and type-only fixes that do not change behavior.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes tsc, unit tests, linting, runtime smoke tests, and API contract checks.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
