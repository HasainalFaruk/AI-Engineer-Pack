# TypeScript Examples

## Implementation example
Request: Use the TypeScript skill to add a small feature in the current repository, follow existing conventions, and verify with tsc, unit tests, linting, runtime smoke tests, and API contract checks.

Expected output: A focused implementation summary, changed files, verification results, and notes about TypeScript-specific risks.

## Review example
Request: Use the TypeScript skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as any types, unsafe casts, mismatched runtime validation, and type-only fixes that do not change behavior.

## Debugging example
Request: Use the TypeScript skill to investigate a failure involving typed JavaScript applications, strict compiler settings, shared types, frontend and backend modules.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
