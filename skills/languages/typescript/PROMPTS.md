## Review
Use the TypeScript skill. Review the change for correctness, maintainability, security, performance, and TypeScript-specific pitfalls such as any types, unsafe casts, mismatched runtime validation, and type-only fixes that do not change behavior. Provide findings by severity.

## Debug
Use the TypeScript skill. Reproduce or reason through the issue, inspect relevant files and runtime signals, identify the likely cause, apply a focused fix if requested, and verify with tsc, unit tests, linting, runtime smoke tests, and API contract checks.

## Document
Use the TypeScript skill. Create documentation that explains setup, usage, configuration, limitations, and troubleshooting for this repository's TypeScript implementation.
