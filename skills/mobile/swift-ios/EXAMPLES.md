# Swift iOS Examples

## Implementation example
Request: Use the Swift iOS skill to add a small feature in the current repository, follow existing conventions, and verify with unit tests, UI smoke tests, concurrency checks, simulator runs, and permission flow validation.

Expected output: A focused implementation summary, changed files, verification results, and notes about Swift iOS-specific risks.

## Review example
Request: Use the Swift iOS skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as main-thread blocking, force unwraps, missing privacy strings, retain cycles, and unhandled offline states.

## Debugging example
Request: Use the Swift iOS skill to investigate a failure involving SwiftUI or UIKit apps, concurrency, persistence, networking, permissions, and App Store-ready behavior.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
