# Swift iOS Checklist

- [ ] The affected Swift iOS files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids main-thread blocking, force unwraps, missing privacy strings, retain cycles, and unhandled offline states.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes unit tests, UI smoke tests, concurrency checks, simulator runs, and permission flow validation.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
