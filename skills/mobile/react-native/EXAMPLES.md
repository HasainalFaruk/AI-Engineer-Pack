# React Native Examples

## Implementation example
Request: Use the React Native skill to add a small feature in the current repository, follow existing conventions, and verify with iOS and Android smoke tests, component tests, navigation checks, native build checks, and device permission tests.

Expected output: A focused implementation summary, changed files, verification results, and notes about React Native-specific risks.

## Review example
Request: Use the React Native skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as assuming platform parity, slow lists, unhandled permissions, native dependency drift, and layout issues on small screens.

## Debugging example
Request: Use the React Native skill to investigate a failure involving cross-platform screens, navigation, native modules, storage, lists, gestures, and platform-specific behavior.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
