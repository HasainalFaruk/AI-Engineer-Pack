# React Native Checklist

- [ ] The affected React Native files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids assuming platform parity, slow lists, unhandled permissions, native dependency drift, and layout issues on small screens.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes iOS and Android smoke tests, component tests, navigation checks, native build checks, and device permission tests.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
