# Flutter Checklist

- [ ] The affected Flutter files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids large rebuild scopes, hard-coded sizes, platform channel errors, untested navigation, and state leaks.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes flutter test, analyzer checks, golden tests, device smoke tests, and build checks.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
