# GitHub Actions Checklist

- [ ] The affected GitHub Actions files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids overbroad tokens, flaky caches, unpinned actions, skipped required checks, and secrets exposed in logs.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes workflow syntax checks, least-privilege permissions, cache key review, branch trigger checks, and dry-run reasoning.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
