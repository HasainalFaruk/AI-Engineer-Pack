## Review
Use the GitHub Actions skill. Review the change for correctness, maintainability, security, performance, and GitHub Actions-specific pitfalls such as overbroad tokens, flaky caches, unpinned actions, skipped required checks, and secrets exposed in logs. Provide findings by severity.

## Debug

Reproduce or reason through the issue, inspect relevant files and runtime signals, identify the likely cause, apply a focused fix if requested, and verify with workflow syntax checks, least-privilege permissions, cache key review, branch trigger checks, and dry-run reasoning.

## Document
