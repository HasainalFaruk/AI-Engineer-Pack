# Docker Examples

## Implementation example
Request: Use the Docker skill to add a small feature in the current repository, follow existing conventions, and verify with docker build, compose smoke tests, image inspection, health checks, and dependency cache validation.

Expected output: A focused implementation summary, changed files, verification results, and notes about Docker-specific risks.

## Review example
Request: Use the Docker skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as running as root, copying secrets, bloated layers, missing health checks, and dev-only settings in production images.

## Debugging example
Request: Use the Docker skill to investigate a failure involving Dockerfiles, compose environments, image size, build caching, runtime users, and local reproducibility.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
