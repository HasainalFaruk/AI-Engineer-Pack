# MongoDB Checklist

- [ ] The affected MongoDB files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids unbounded collections scans, inconsistent document shapes, oversized documents, and missing compound indexes.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes index explain plans, aggregation tests, fixture-backed queries, and migration sampling.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
