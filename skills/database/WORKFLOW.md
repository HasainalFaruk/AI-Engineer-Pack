# Database Workflow

## 1. Understand
Identify the user outcome, affected system, constraints, non-goals, and definition of done.

## 2. Inspect
Review relevant files, configuration, dependencies, documentation, and existing patterns before changing anything.

## 3. Decide
Choose the simplest approach that satisfies the requirement and follows repository conventions.

## 4. Execute
Make focused changes or produce the requested guidance. Keep scope tight and document meaningful decisions.

## 5. Verify
Run appropriate tests, checks, reviews, or manual validation. Broaden verification when shared behavior or production workflows are affected.

## 6. Handoff
Summarize what changed, how it was verified, assumptions made, and residual risks.
