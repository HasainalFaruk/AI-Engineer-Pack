# Architecture Skill Definition

## Capability
Use this skill to handle architecture tasks with repository awareness, professional engineering judgment, and measurable verification.

## Best For
- Clarifying requirements and constraints.
- Selecting appropriate tools, patterns, and implementation approaches.
- Producing plans, code changes, reviews, documentation, and debugging paths.
- Identifying domain-specific risks, edge cases, and tests.

## Inputs
- User goal and acceptance criteria.
- Existing repository context and conventions.
- Runtime, dependency, security, performance, and maintenance constraints.

## Outputs
- A focused plan or implementation.
- Rationale for important decisions.
- Verification steps and test expectations.
- Documentation updates when behavior, setup, or usage changes.
