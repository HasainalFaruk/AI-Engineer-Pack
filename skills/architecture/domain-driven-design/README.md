# Domain-Driven Design Skill

## Purpose
The Domain-Driven Design skill supports bounded contexts, aggregates, value objects, domain services, ubiquitous language, and context mapping. It gives AI assistants concrete guidance for planning, implementation, review, debugging, and documentation in this technology area.
