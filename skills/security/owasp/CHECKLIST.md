# OWASP Web Security Checklist

- [ ] The affected OWASP Web Security files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids trusting client input, missing authorization checks, weak session handling, and output without escaping.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes threat checks, security tests, dependency scanning, header review, and abuse-case testing.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
