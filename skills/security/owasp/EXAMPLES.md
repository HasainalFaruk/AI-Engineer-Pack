# OWASP Web Security Examples

## Implementation example
Request: Use the OWASP Web Security skill to add a small feature in the current repository, follow existing conventions, and verify with threat checks, security tests, dependency scanning, header review, and abuse-case testing.

Expected output: A focused implementation summary, changed files, verification results, and notes about OWASP Web Security-specific risks.

## Review example
Request: Use the OWASP Web Security skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as trusting client input, missing authorization checks, weak session handling, and output without escaping.

## Debugging example
Request: Use the OWASP Web Security skill to investigate a failure involving web application risks including injection, XSS, CSRF, authentication, access control, and secure headers.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
