# Authentication Checklist

- [ ] The affected Authentication files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids long-lived tokens, weak reset flows, missing lockout, insecure cookies, and confusing authentication with authorization.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes token expiry tests, session invalidation checks, rate limit tests, MFA flows, and replay protection review.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
