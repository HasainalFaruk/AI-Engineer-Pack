# Authentication Examples

## Implementation example
Request: Use the Authentication skill to add a small feature in the current repository, follow existing conventions, and verify with token expiry tests, session invalidation checks, rate limit tests, MFA flows, and replay protection review.

Expected output: A focused implementation summary, changed files, verification results, and notes about Authentication-specific risks.

## Review example
Request: Use the Authentication skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as long-lived tokens, weak reset flows, missing lockout, insecure cookies, and confusing authentication with authorization.

## Debugging example
Request: Use the Authentication skill to investigate a failure involving login flows, sessions, tokens, password reset, MFA, identity providers, and account recovery.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
