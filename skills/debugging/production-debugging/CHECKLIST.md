# Production Debugging Checklist

- [ ] The affected Production Debugging files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids making risky live changes, trusting one signal, no incident timeline, missing customer impact, and no follow-up prevention.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes timeline reconstruction, metric correlation, safe probes, rollback validation, and post-incident regression checks.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
