# Production Debugging Examples

## Implementation example
Request: Use the Production Debugging skill to add a small feature in the current repository, follow existing conventions, and verify with timeline reconstruction, metric correlation, safe probes, rollback validation, and post-incident regression checks.

Expected output: A focused implementation summary, changed files, verification results, and notes about Production Debugging-specific risks.

## Review example
Request: Use the Production Debugging skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as making risky live changes, trusting one signal, no incident timeline, missing customer impact, and no follow-up prevention.

## Debugging example
Request: Use the Production Debugging skill to investigate a failure involving live incident diagnosis using logs, metrics, traces, feature flags, rollbacks, and customer impact analysis.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
