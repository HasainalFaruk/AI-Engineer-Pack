# Browser DevTools Examples

## Implementation example
Request: Use the Browser DevTools skill to add a small feature in the current repository, follow existing conventions, and verify with console error review, network trace inspection, performance profiles, DOM checks, and device emulation.

Expected output: A focused implementation summary, changed files, verification results, and notes about Browser DevTools-specific risks.

## Review example
Request: Use the Browser DevTools skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as debugging minified output only, ignoring network failures, changing CSS blindly, and not reproducing on target viewport.

## Debugging example
Request: Use the Browser DevTools skill to investigate a failure involving frontend runtime debugging with console, network, performance, accessibility, storage, and layout tooling.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
