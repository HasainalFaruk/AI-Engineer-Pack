# Browser DevTools Checklist

- [ ] The affected Browser DevTools files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids debugging minified output only, ignoring network failures, changing CSS blindly, and not reproducing on target viewport.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes console error review, network trace inspection, performance profiles, DOM checks, and device emulation.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
