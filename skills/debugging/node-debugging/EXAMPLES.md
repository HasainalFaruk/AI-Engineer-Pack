# Node.js Debugging Examples

## Implementation example
Request: Use the Node.js Debugging skill to add a small feature in the current repository, follow existing conventions, and verify with targeted reproduction, log correlation, inspector sessions, heap snapshots, and integration tests.

Expected output: A focused implementation summary, changed files, verification results, and notes about Node.js Debugging-specific risks.

## Review example
Request: Use the Node.js Debugging skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as swallowing promise rejections, ignoring event loop blocking, broad dependency upgrades, and missing env parity.

## Debugging example
Request: Use the Node.js Debugging skill to investigate a failure involving Node services, async call stacks, memory leaks, event loop delay, package issues, and server logs.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
