# React Checklist

- [ ] The affected React files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids state duplicated across components, unstable keys, missing labels, effect dependency bugs, and layout shifts.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes component tests, accessibility checks, interaction tests, build checks, and visual smoke testing.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
