# WordPress Examples

## Implementation example
Request: Use the WordPress skill to add a small feature in the current repository, follow existing conventions, and verify with local WordPress smoke tests, PHP linting, nonce checks, role checks, and plugin activation tests.

Expected output: A focused implementation summary, changed files, verification results, and notes about WordPress-specific risks.

## Review example
Request: Use the WordPress skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as missing escaping, missing nonces, direct database queries, global state surprises, and update-unsafe customizations.

## Debugging example
Request: Use the WordPress skill to investigate a failure involving themes, plugins, hooks, shortcodes, Gutenberg blocks, custom post types, and secure admin workflows.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
