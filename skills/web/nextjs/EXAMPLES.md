# Next.js Examples

## Implementation example
Request: Use the Next.js skill to add a small feature in the current repository, follow existing conventions, and verify with build checks, route smoke tests, server/client boundary checks, metadata validation, and cache behavior tests.

Expected output: A focused implementation summary, changed files, verification results, and notes about Next.js-specific risks.

## Review example
Request: Use the Next.js skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as misplaced client components, stale caches, secret leakage to the browser, and dynamic routes without loading or error states.

## Debugging example
Request: Use the Next.js skill to investigate a failure involving routing, server and client components, data fetching, caching, middleware, API routes, and deployment behavior.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
