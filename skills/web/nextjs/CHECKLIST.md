# Next.js Checklist

- [ ] The affected Next.js files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids misplaced client components, stale caches, secret leakage to the browser, and dynamic routes without loading or error states.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes build checks, route smoke tests, server/client boundary checks, metadata validation, and cache behavior tests.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
