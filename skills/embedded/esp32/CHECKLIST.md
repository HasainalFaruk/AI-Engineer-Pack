# ESP32 Checklist

- [ ] The affected ESP32 files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids blocking network calls, watchdog resets, unsafe OTA, credential storage issues, and concurrency races.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes firmware build, serial logs, Wi-Fi reconnect tests, task watchdog checks, and power draw review.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
