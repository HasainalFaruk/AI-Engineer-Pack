# ESP32 Skill

## Purpose
The ESP32 skill supports Wi-Fi, Bluetooth, FreeRTOS tasks, GPIO, power modes, OTA updates, and embedded networking. It gives AI assistants concrete guidance for planning, implementation, review, debugging, and documentation in this technology area.

## Contents
- [SKILL.md](SKILL.md): capability boundaries and expected outputs.
- [WORKFLOW.md](WORKFLOW.md): technology-specific execution process.
- [PROMPTS.md](PROMPTS.md): reusable prompts for ESP32 work.
- [CHECKLIST.md](CHECKLIST.md): verification and quality checks.
- [EXAMPLES.md](EXAMPLES.md): practical scenarios and outputs.

## Usage
Use this skill when a task specifically involves ESP32 decisions, files, tools, runtime behavior, or failure modes. Combine it with the parent [category skill](../README.md), relevant [commands](../../../commands/README.md), and [frameworks](../../../frameworks/README.md).
