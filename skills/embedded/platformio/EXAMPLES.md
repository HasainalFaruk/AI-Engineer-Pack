# PlatformIO Examples

## Implementation example
Request: Use the PlatformIO skill to add a small feature in the current repository, follow existing conventions, and verify with pio run, environment matrix builds, library lock review, upload smoke tests, and unit tests where available.

Expected output: A focused implementation summary, changed files, verification results, and notes about PlatformIO-specific risks.

## Review example
Request: Use the PlatformIO skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as environment drift, board mismatch, unpinned libraries, hidden upload settings, and missing serial diagnostics.

## Debugging example
Request: Use the PlatformIO skill to investigate a failure involving multi-board embedded projects, library dependencies, build environments, upload targets, and test automation.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
