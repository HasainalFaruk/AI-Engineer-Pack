# PlatformIO Checklist

- [ ] The affected PlatformIO files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids environment drift, board mismatch, unpinned libraries, hidden upload settings, and missing serial diagnostics.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes pio run, environment matrix builds, library lock review, upload smoke tests, and unit tests where available.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
