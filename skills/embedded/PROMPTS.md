# Embedded Prompts

## Planning
Use the $cat skill. Inspect the current repository, identify constraints, propose a concise implementation plan, and define verification steps.

## Implementation
Use the $cat skill. Implement the requested change in the current repository, follow existing conventions, update documentation where needed, and verify the result.

## Review
Use the $cat skill. Review the change for correctness, maintainability, security, performance, missing tests, and documentation gaps. Report findings by severity with file references.

## Debugging
Use the $cat skill. Reproduce or reason through the issue, inspect relevant paths, apply a focused fix, and verify the behavior.
