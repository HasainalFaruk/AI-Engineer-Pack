# pytest Examples

## Implementation example
Request: Use the pytest skill to add a small feature in the current repository, follow existing conventions, and verify with pytest targeted runs, fixture scope review, coverage checks, and failure reproduction.

Expected output: A focused implementation summary, changed files, verification results, and notes about pytest-specific risks.

## Review example
Request: Use the pytest skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as overbroad fixtures, order-dependent tests, excessive mocking, slow integration tests in unit layers, and unclear assertions.

## Debugging example
Request: Use the pytest skill to investigate a failure involving Python test suites, fixtures, parametrization, plugins, mocking, coverage, and regression tests.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
