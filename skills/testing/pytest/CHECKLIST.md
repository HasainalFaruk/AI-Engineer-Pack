# pytest Checklist

- [ ] The affected pytest files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids overbroad fixtures, order-dependent tests, excessive mocking, slow integration tests in unit layers, and unclear assertions.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes pytest targeted runs, fixture scope review, coverage checks, and failure reproduction.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
