# Playwright Prompts

## Build
Use the Playwright skill. Inspect existing project conventions, implement the requested change using idiomatic Playwright patterns, verify with headed and headless runs, trace review, selector stability checks, network mocking, and screenshot validation, and summarize changed files and risks.

## Review
Use the Playwright skill. Review the change for correctness, maintainability, security, performance, and Playwright-specific pitfalls such as fragile selectors, missing waits for user-visible state, overlong journeys, and tests that depend on external services. Provide findings by severity.

## Debug
Use the Playwright skill. Reproduce or reason through the issue, inspect relevant files and runtime signals, identify the likely cause, apply a focused fix if requested, and verify with headed and headless runs, trace review, selector stability checks, network mocking, and screenshot validation.

## Document
Use the Playwright skill. Create documentation that explains setup, usage, configuration, limitations, and troubleshooting for this repository's Playwright implementation.
