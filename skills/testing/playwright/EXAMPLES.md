# Playwright Examples

## Implementation example
Request: Use the Playwright skill to add a small feature in the current repository, follow existing conventions, and verify with headed and headless runs, trace review, selector stability checks, network mocking, and screenshot validation.

Expected output: A focused implementation summary, changed files, verification results, and notes about Playwright-specific risks.

## Review example
Request: Use the Playwright skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as fragile selectors, missing waits for user-visible state, overlong journeys, and tests that depend on external services.

## Debugging example
Request: Use the Playwright skill to investigate a failure involving browser automation, end-to-end flows, accessibility smoke checks, visual verification, and cross-browser behavior.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
