# Playwright Checklist

- [ ] The affected Playwright files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids fragile selectors, missing waits for user-visible state, overlong journeys, and tests that depend on external services.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes headed and headless runs, trace review, selector stability checks, network mocking, and screenshot validation.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
