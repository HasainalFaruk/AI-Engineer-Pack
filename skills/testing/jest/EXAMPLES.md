# Jest Examples

## Implementation example
Request: Use the Jest skill to add a small feature in the current repository, follow existing conventions, and verify with jest targeted runs, fake timer checks, snapshot review, coverage checks, and mock cleanup.

Expected output: A focused implementation summary, changed files, verification results, and notes about Jest-specific risks.

## Review example
Request: Use the Jest skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as brittle snapshots, leaky mocks, testing implementation details, unawaited promises, and timer misuse.

## Debugging example
Request: Use the Jest skill to investigate a failure involving JavaScript and TypeScript unit tests, mocks, timers, snapshots, module boundaries, and frontend logic.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
