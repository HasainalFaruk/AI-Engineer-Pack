# Jest Checklist

- [ ] The affected Jest files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids brittle snapshots, leaky mocks, testing implementation details, unawaited promises, and timer misuse.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes jest targeted runs, fake timer checks, snapshot review, coverage checks, and mock cleanup.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
