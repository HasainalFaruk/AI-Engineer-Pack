# Strapi Checklist

- [ ] The affected Strapi files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids open permissions, migration surprises, business logic hidden in lifecycle hooks, and unvalidated custom controllers.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes API smoke tests, role permission checks, schema migration review, and admin workflow checks.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
