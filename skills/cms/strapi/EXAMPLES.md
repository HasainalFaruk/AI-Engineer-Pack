# Strapi Examples

## Implementation example
Request: Use the Strapi skill to add a small feature in the current repository, follow existing conventions, and verify with API smoke tests, role permission checks, schema migration review, and admin workflow checks.

Expected output: A focused implementation summary, changed files, verification results, and notes about Strapi-specific risks.

## Review example
Request: Use the Strapi skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as open permissions, migration surprises, business logic hidden in lifecycle hooks, and unvalidated custom controllers.

## Debugging example
Request: Use the Strapi skill to investigate a failure involving content types, controllers, policies, lifecycle hooks, permissions, and headless CMS APIs.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
