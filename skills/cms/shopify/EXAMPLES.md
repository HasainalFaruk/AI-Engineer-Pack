# Shopify Examples

## Implementation example
Request: Use the Shopify skill to add a small feature in the current repository, follow existing conventions, and verify with theme checks, GraphQL query validation, extension preview, test store smoke checks, and webhook verification.

Expected output: A focused implementation summary, changed files, verification results, and notes about Shopify-specific risks.

## Review example
Request: Use the Shopify skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as unscoped metafields, brittle theme edits, missing webhook idempotency, and API version drift.

## Debugging example
Request: Use the Shopify skill to investigate a failure involving Liquid themes, app integration, Admin API workflows, metafields, checkout extensions, and storefront behavior.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
