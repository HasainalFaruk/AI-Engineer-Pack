# Shopify Checklist

- [ ] The affected Shopify files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids unscoped metafields, brittle theme edits, missing webhook idempotency, and API version drift.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes theme checks, GraphQL query validation, extension preview, test store smoke checks, and webhook verification.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
