# Drupal Checklist

- [ ] The affected Drupal files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids hard-coded config, missing access callbacks, cache metadata mistakes, and update hooks without rollback thinking.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes cache rebuilds, config import/export checks, permission tests, and module install smoke tests.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
