# Drupal Examples

## Implementation example
Request: Use the Drupal skill to add a small feature in the current repository, follow existing conventions, and verify with cache rebuilds, config import/export checks, permission tests, and module install smoke tests.

Expected output: A focused implementation summary, changed files, verification results, and notes about Drupal-specific risks.

## Review example
Request: Use the Drupal skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as hard-coded config, missing access callbacks, cache metadata mistakes, and update hooks without rollback thinking.

## Debugging example
Request: Use the Drupal skill to investigate a failure involving modules, entities, fields, routes, permissions, configuration export, and content modeling.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
