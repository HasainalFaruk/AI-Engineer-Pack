# PyTorch Examples

## Implementation example
Request: Use the PyTorch skill to add a small feature in the current repository, follow existing conventions, and verify with shape tests, small-batch overfit checks, checkpoint load tests, deterministic seeds, and inference smoke tests.

Expected output: A focused implementation summary, changed files, verification results, and notes about PyTorch-specific risks.

## Review example
Request: Use the PyTorch skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as silent shape bugs, device mismatch, missing eval mode, unstable training loops, and untracked experiment config.

## Debugging example
Request: Use the PyTorch skill to investigate a failure involving neural network training loops, datasets, dataloaders, tensors, GPU usage, checkpoints, and inference code.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
