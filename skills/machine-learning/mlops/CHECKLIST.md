# MLOps Checklist

- [ ] The affected MLOps files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids training-serving skew, unversioned data, no model lineage, missing drift alerts, and manual promotion steps.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes reproducible pipeline runs, model registry checks, data contracts, monitoring alerts, and rollback drills.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
