# scikit-learn Examples

## Implementation example
Request: Use the scikit-learn skill to add a small feature in the current repository, follow existing conventions, and verify with train/test split checks, cross-validation, metric review, pipeline serialization tests, and leakage audits.

Expected output: A focused implementation summary, changed files, verification results, and notes about scikit-learn-specific risks.

## Review example
Request: Use the scikit-learn skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as data leakage, fitting preprocessors outside pipelines, weak baselines, metric mismatch, and irreproducible random seeds.

## Debugging example
Request: Use the scikit-learn skill to investigate a failure involving classical ML pipelines, preprocessing, feature engineering, model selection, cross-validation, and reproducible training.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
