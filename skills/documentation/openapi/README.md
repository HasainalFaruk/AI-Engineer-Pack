# OpenAPI Skill

## Purpose
The OpenAPI skill supports REST API contracts, schemas, examples, error responses, authentication, and generated documentation. It gives AI assistants concrete guidance for planning, implementation, review, debugging, and documentation in this technology area.

## Contents
- [SKILL.md](SKILL.md): capability boundaries and expected outputs.
- [WORKFLOW.md](WORKFLOW.md): technology-specific execution process.
- [PROMPTS.md](PROMPTS.md): reusable prompts for OpenAPI work.
- [CHECKLIST.md](CHECKLIST.md): verification and quality checks.
- [EXAMPLES.md](EXAMPLES.md): practical scenarios and outputs.

## Usage
Use this skill when a task specifically involves OpenAPI decisions, files, tools, runtime behavior, or failure modes. Combine it with the parent [category skill](../README.md), relevant [commands](../../../commands/README.md), and [frameworks](../../../frameworks/README.md).
