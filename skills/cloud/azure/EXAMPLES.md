# Azure Examples

## Implementation example
Request: Use the Azure skill to add a small feature in the current repository, follow existing conventions, and verify with role assignment review, deployment plan checks, Key Vault access tests, logs, metrics, and health probes.

Expected output: A focused implementation summary, changed files, verification results, and notes about Azure-specific risks.

## Review example
Request: Use the Azure skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as overbroad roles, secrets in app settings, missing managed identities, and unclear resource ownership.

## Debugging example
Request: Use the Azure skill to investigate a failure involving Azure App Service, Functions, Entra ID, Storage, Key Vault, Monitor, networking, and resource groups.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
