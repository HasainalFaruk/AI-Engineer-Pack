# AWS Examples

## Implementation example
Request: Use the AWS skill to add a small feature in the current repository, follow existing conventions, and verify with IAM policy review, infrastructure plan checks, log and metric validation, least privilege review, and cost estimation.

Expected output: A focused implementation summary, changed files, verification results, and notes about AWS-specific risks.

## Review example
Request: Use the AWS skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as wildcard IAM, public buckets, missing alarms, region drift, and untagged cost centers.

## Debugging example
Request: Use the AWS skill to investigate a failure involving IAM, Lambda, ECS, S3, RDS, CloudWatch, networking, cost controls, and deployment architecture.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
