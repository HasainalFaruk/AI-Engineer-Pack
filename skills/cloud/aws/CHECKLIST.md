# AWS Checklist

- [ ] The affected AWS files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids wildcard IAM, public buckets, missing alarms, region drift, and untagged cost centers.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes IAM policy review, infrastructure plan checks, log and metric validation, least privilege review, and cost estimation.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
