# Google Cloud Checklist

- [ ] The affected Google Cloud files, configuration, and runtime path are identified.
- [ ] Existing repository conventions and dependency versions are respected.
- [ ] The solution avoids default service account misuse, public storage, missing concurrency limits, and project sprawl.
- [ ] Security, reliability, and maintainability concerns are reviewed.
- [ ] Verification includes IAM review, deployment smoke tests, service account checks, log-based metrics, and budget alert review.
- [ ] Documentation or examples are updated when setup, behavior, or usage changes.
- [ ] The final summary names residual risks and any checks not run.
