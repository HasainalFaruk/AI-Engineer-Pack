# Google Cloud Examples

## Implementation example
Request: Use the Google Cloud skill to add a small feature in the current repository, follow existing conventions, and verify with IAM review, deployment smoke tests, service account checks, log-based metrics, and budget alert review.

Expected output: A focused implementation summary, changed files, verification results, and notes about Google Cloud-specific risks.

## Review example
Request: Use the Google Cloud skill to review a pull request for correctness and risks.

Expected output: Severity-ranked findings that call out issues such as default service account misuse, public storage, missing concurrency limits, and project sprawl.

## Debugging example
Request: Use the Google Cloud skill to investigate a failure involving Cloud Run, Cloud Functions, IAM, Pub/Sub, Cloud SQL, storage, logging, and project-level governance.

Expected output: Root cause, focused fix or recommendation, verification evidence, and remaining uncertainty.
