# Performance Checklist

## Purpose
This checklist validates Performance work before it is considered complete.

## Contents
- Scope confirmation.
- Quality criteria.
- Risk checks.
- Verification expectations.
- Handoff requirements.

## Usage
Apply this checklist near the end of a task and during review. Any unchecked item should be documented as a risk or follow-up.

## Checklist
- [ ] The goal and scope are clear.
- [ ] Affected files, systems, or users are identified.
- [ ] The solution follows repository conventions.
- [ ] Edge cases and failure modes are considered.
- [ ] Security, privacy, and compliance risks are addressed where applicable.
- [ ] Performance and reliability impacts are understood.
- [ ] Tests or manual checks cover important behavior.
- [ ] Documentation is updated where setup, behavior, or usage changed.
- [ ] Handoff states what changed, how it was verified, and residual risk.
