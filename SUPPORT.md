# Support

## Getting help
The AI Engineer Pack is maintained as a documentation and workflow resource for AI-assisted engineering. Use GitHub issues to ask for help with repository content, propose improvements, or report problems.

## Best place to ask
Choose the issue type that matches your need:

- Bug report: incorrect, broken, misleading, or incomplete content.
- Feature request: a new command, framework, template, checklist, example, or repository improvement.
- Documentation improvement: unclear wording, broken links, stale examples, or missing explanation.
- Skill request: a new skill category, technology-specific skill, or improvement to an existing skill.

## Before opening an issue
Please:

1. Search existing issues for duplicates.
2. Identify the relevant file or folder path.
3. Explain the practical impact for ChatGPT, Codex, GitHub Copilot, OpenAI Agents, future assistants, or human contributors.
4. Include examples, expected behavior, and suggested wording when possible.
5. Review [CONTRIBUTING.md](CONTRIBUTING.md) if you plan to submit a pull request.

## What this project can support
Good support requests include:

- How to structure a new skill under `skills/`.
- Whether a framework page describes the real methodology accurately.
- Missing examples in a command, template, checklist, or skill.
- Broken links, placeholders, formatting issues, or duplicate guidance.
- Suggestions for improving AI assistant usability across the pack.

## What this project cannot support
This repository does not provide:

- Emergency production incident support.
- Custom consulting for private codebases.
- Legal, medical, financial, or compliance advice.
- Guaranteed support for every AI coding assistant or third-party tool.
- Help with unrelated software projects that do not affect this pack.

## Security issues
Do not disclose sensitive security issues in public issues. Follow [SECURITY.md](SECURITY.md) for reporting guidance.

## Maintainer response
Maintainers triage issues by impact, clarity, and alignment with the AI Engineer Pack roadmap. Clear reproduction details, affected paths, and suggested fixes help issues move faster.
