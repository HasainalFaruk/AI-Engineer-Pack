# Contributing

## Standards
- Use Markdown.
- Write specific, actionable guidance.
- Cross-link related files.
- Include examples when a pattern could be misunderstood.
- Preserve standard file sets for skills and templates.

## Adding a Skill
1. Create or reuse a category under `skills/`.
2. Include `README.md`, `SKILL.md`, `WORKFLOW.md`, `PROMPTS.md`, `CHECKLIST.md`, and `EXAMPLES.md`.
3. Explain scope, workflow, prompts, checks, and examples.

## Review Expectations
Before merging, verify completeness, link quality, examples, and measurable checklists.
