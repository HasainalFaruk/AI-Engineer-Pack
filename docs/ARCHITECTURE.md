# Architecture

## Content Layers
1. `system/` defines operating principles.
2. `routers/` selects workflows.
3. `frameworks/` structures prompts.
4. `commands/` defines task verbs.
5. `skills/` adds domain execution guidance.
6. `templates/` starts common artifacts.
7. `checklists/` validates delivery.
8. `examples/` demonstrates usage.
9. `docs/` governs maintenance.

## Design Principles
- Make documentation composable.
- Keep each folder understandable on its own.
- Link related concepts explicitly.
- Produce verifiable outcomes.
- Update checklists when new risks are discovered.
