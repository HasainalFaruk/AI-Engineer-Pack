# FAQ

## What is the AI Engineer Pack?
It is a structured set of documentation, prompts, workflows, templates, and checklists for AI-assisted software engineering.

## Which assistants can use it?
It is designed for ChatGPT, Codex, GitHub Copilot, OpenAI Agents, and future AI coding assistants.

## How do I start a task?
Route the request, choose a command, select a framework, apply a skill, and validate with a checklist.

## How do I add a new domain?
Add a skill category under `skills/` with the standard six files and cross-link related commands, templates, and checklists.
