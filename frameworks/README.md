# Frameworks

## Purpose
The `frameworks` folder documents prompt engineering methodologies that help AI assistants understand context, choose a reasoning style, produce useful outputs, and validate results.

## Contents
- [BAB](bab/README.md): Before, After, Bridge for transformation and persuasion.
- [CARE](care/README.md): Context, Action, Result, Example for practical task prompts.
- [Chain of Thought](chain-of-thought/README.md): concise stepwise reasoning for multi-step analysis.
- [CO-STAR](co-star/README.md): Context, Objective, Style, Tone, Audience, Response for audience-aware outputs.
- [CRISPE](crispe/README.md): role, insight, task, personality, and experiment framing.
- [Least-to-Most](least-to-most/README.md): dependency-ordered decomposition from simpler subproblems to harder ones.
- [Plan and Solve](plan-and-solve/README.md): plan-first execution for multi-step work.
- [ReAct](react/README.md): reasoning plus tool actions for evidence-based investigation.
- [Reflection](reflection/README.md): post-output critique against explicit criteria.
- [Reverse Prompting](reverse-prompting/README.md): deriving reusable prompts from desired outputs.
- [RISE](rise/README.md): Role, Input, Steps, Expectation for compact task prompts.
- [Self-Refine](self-refine/README.md): draft, critique, revise, and verify loops.
- [Skeleton of Thought](skeleton-of-thought/README.md): outline-first expansion for long-form work.
- [Tree of Thought](tree-of-thought/README.md): branching alternatives and evaluation before selecting a path.

## Usage
Choose the framework that matches the work style needed by the request. Use communication frameworks such as CO-STAR, RISE, CRISPE, BAB, and CARE when output fit matters. Use reasoning frameworks such as ReAct, Tree of Thought, Chain of Thought, Plan and Solve, Self-Refine, Reflection, Skeleton of Thought, Least-to-Most, and Reverse Prompting when the task requires investigation, decomposition, critique, or reuse.
