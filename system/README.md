# System

## Purpose
The `system` folder contains repository-wide operating principles, assistant behavior rules, quality standards, and safety guardrails for AI engineering work.

## Contents
- Durable instructions for AI coding assistants.
- Quality expectations for generated code and documentation.
- Guardrails for safety, scope control, verification, and handoff.

## Usage
Start here when configuring ChatGPT, Codex, GitHub Copilot, OpenAI Agents, or future assistants for this repository. Combine system guidance with commands, frameworks, skills, and checklists for task execution.
