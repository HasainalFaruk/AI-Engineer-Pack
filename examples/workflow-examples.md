# Workflow Examples

## Build a REST API
1. Use [commands/build](../commands/build/README.md).
2. Use [templates/rest-api](../templates/rest-api/README.md).
3. Use [skills/web](../skills/web/README.md), [skills/database](../skills/database/README.md), and [skills/security](../skills/security/README.md).
4. Validate with [checklists/testing](../checklists/testing/README.md), [checklists/security](../checklists/security/README.md), and [checklists/documentation](../checklists/documentation/README.md).

## Review a Pull Request
1. Use [commands/review](../commands/review/README.md).
2. Use the domain skill that matches the changed code.
3. Validate with [checklists/code-review](../checklists/code-review/README.md).
4. Report findings by severity with file references and suggested fixes.

## Debug a Production Issue
1. Use [commands/debug](../commands/debug/README.md).
2. Use [frameworks/react](../frameworks/react/README.md) or [frameworks/plan-and-solve](../frameworks/plan-and-solve/README.md).
3. Use [skills/debugging](../skills/debugging/README.md) and domain-specific skills.
4. Validate with regression tests and an incident summary.
