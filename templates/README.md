# Templates

## Purpose
The `templates` folder contains starter plans and documentation structures for common software projects and technical artifacts.

## Contents
- API, application, CMS, embedded, machine learning, RAG, CLI, microservice, Docker, and GitHub Action templates.
- Project brief, architecture, implementation, testing, and delivery sections.
- Cross-links to related skills, commands, and checklists.

## Usage
Use a template when starting a new artifact or project plan. Replace example sections with concrete requirements, interfaces, dependencies, acceptance criteria, and verification steps.
