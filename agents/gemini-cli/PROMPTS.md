# Gemini CLI Prompt Patterns

## Build prompt
Use Gemini CLI to complete a scoped task. Inspect context first, explain assumptions, ask before risky actions, and return evidence plus verification.

## Review prompt
Review this Gemini CLI design for permissions, state handling, prompt injection risk, failure recovery, observability, and deployment readiness.

## Debug prompt
Debug this failed Gemini CLI run. Inspect prompts, tool logs, state, traces, and final output. Identify the first bad decision and a regression check.

## Hardening prompt
Harden this Gemini CLI workflow for production with least-privilege tools, approval gates, tests, monitoring, and rollback guidance.

## Pattern notes
Give a concrete terminal task, scope, files, command policy, desired verification, and whether the agent can edit files or only inspect.
