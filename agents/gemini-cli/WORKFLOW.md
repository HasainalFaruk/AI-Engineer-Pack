# Gemini CLI Workflow

## 1. Define the outcome
Write the goal, non-goals, success metrics, and approval boundaries.

## 2. Configure the environment
Install or enable the runtime, configure credentials, add repository instructions, and verify tool permissions.

## 3. Start with inspection
Ask the agent to inspect, plan, or summarize before granting write access.

## 4. Execute scoped work
Install CLI, authenticate, add GEMINI.md, run scoped prompts, inspect diffs, run tests, checkpoint progress, and use GitHub Action for repeatable automation.

## 5. Verify behavior
Run project tests, validate shell output, compare checkpoints, test MCP integrations, and review GitHub Action behavior on pull requests..

## 6. Deploy gradually
Use through CI or terminal workflows with explicit secrets, restricted permissions, and human approval for merges or production changes..

## 7. Improve from evidence
Review traces, logs, failed evals, and human overrides before increasing autonomy.
