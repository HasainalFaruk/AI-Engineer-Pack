# Claude Code Examples

## Safe repository review
Use Claude Code to inspect a pull request, summarize risk, and recommend fixes without merging, deploying, or modifying secrets.

## Tool-using support workflow
Use Claude Code with read-only lookup tools to triage a support ticket, identify likely cause, and escalate sensitive account actions.

## Production workflow
Write tests for an auth module; fix failing CI; generate release notes; run parallel agents for docs and tests; automate weekly dependency audit.

## Output contract
- Summary of action.
- Evidence consulted.
- Decision or artifact.
- Risks and escalation needs.
- Verification completed.
