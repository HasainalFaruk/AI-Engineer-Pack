# GitHub Copilot Workflow

## 1. Define the task
Write the goal, acceptance criteria, files or systems in scope, and actions that require approval.

## 2. Configure the environment
Install or enable the tool, connect required services, configure repository instructions, and verify permissions.

## 3. Start with read-only work
Ask the agent to inspect, summarize, or plan before granting write access.

## 4. Execute scoped work
Configure access, add repo instructions, select Copilot surface, ask for scoped work, review generated changes, run CI, and merge through normal branch protections.

## 5. Verify behavior
Use CI, required checks, Copilot custom-agent tests, review comments, and security scanning before accepting agent changes..

## 6. Review and deploy
Deploy through GitHub Actions or existing pipelines with branch protections, environment approvals, secrets policies, and audit trails..

## 7. Improve from failures
Review failed runs, prompts, traces, logs, and human corrections before increasing autonomy.
