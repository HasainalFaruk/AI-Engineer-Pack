# GitHub Copilot Prompt Patterns

## Build prompt
Use GitHub Copilot to complete a scoped engineering task. Inspect context first, list assumptions, request approval before risky actions, and return changed files plus verification.

## Review prompt
Review this GitHub Copilot workflow for permissions, state handling, prompt injection risk, observability, and deployment readiness. Return severity-ranked findings.

## Debug prompt
Debug this failed GitHub Copilot run. Inspect prompts, tool logs, state, traces, and final output. Identify the first bad decision and propose a regression check.

## Hardening prompt
Harden this GitHub Copilot setup for production by adding least-privilege permissions, approval gates, tests, monitoring, and rollback guidance.

## Prompt pattern notes
Reference issue or PR context, desired files, coding standards, tests, and review expectations; ask for a PR-ready change with verification evidence.
