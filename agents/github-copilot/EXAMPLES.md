# GitHub Copilot Examples

## Safe repository review
Use GitHub Copilot to inspect a pull request, summarize risk, and recommend fixes without merging, deploying, or modifying secrets.

## Tool-using support workflow
Use GitHub Copilot with read-only lookup tools to triage a support ticket, identify likely cause, and escalate sensitive account actions.

## Production workflow
Generate PR summary; triage issues; run cloud agent for a bug fix; configure custom repository agent; review a security-sensitive PR.

## Output contract
- Summary of action.
- Evidence consulted.
- Decision or artifact.
- Risks and escalation needs.
- Verification completed.
