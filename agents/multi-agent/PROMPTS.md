# Multi-Agent Systems Prompt Patterns

## Build prompt
Use Multi-Agent Systems to complete a scoped task. Inspect context first, explain assumptions, ask before risky actions, and return evidence plus verification.

## Review prompt
Review this Multi-Agent Systems design for permissions, state handling, prompt injection risk, failure recovery, observability, and deployment readiness.

## Debug prompt
Debug this failed Multi-Agent Systems run. Inspect prompts, tool logs, state, traces, and final output. Identify the first bad decision and a regression check.

## Hardening prompt
Harden this Multi-Agent Systems workflow for production with least-privilege tools, approval gates, tests, monitoring, and rollback guidance.

## Pattern notes
Give each agent a role, authority boundary, input contract, output contract, escalation rule, and communication protocol.
