# Multi-Agent Systems Examples

## Safe repository review
Inspect a pull request, summarize risk, recommend fixes, and refuse to merge, deploy, or modify secrets.

## Tool-using support workflow
Use read-only lookup tools to triage a support ticket, explain uncertainty, and escalate sensitive account actions.

## Production workflow
Planner-executor-reviewer software task; supervisor-routed support triage; research team with source verifier; incident response team with human approval.

## Output contract
- Summary of action.
- Evidence consulted.
- Decision or artifact.
- Risks and escalation needs.
- Verification completed.
