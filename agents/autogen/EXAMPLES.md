# Microsoft AutoGen Examples

## Safe repository review
Use Microsoft AutoGen to inspect a pull request, summarize risk, and recommend fixes without merging, deploying, or modifying secrets.

## Tool-using support workflow
Use Microsoft AutoGen with read-only lookup tools to triage a support ticket, identify likely cause, and escalate sensitive account actions.

## Production workflow
Two-agent code review; distributed research team; AutoGen Studio prototype for support workflow; Docker-backed code execution evaluator.

## Output contract
- Summary of action.
- Evidence consulted.
- Decision or artifact.
- Risks and escalation needs.
- Verification completed.
