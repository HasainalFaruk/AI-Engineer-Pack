# Microsoft AutoGen Prompt Patterns

## Build prompt
Use Microsoft AutoGen to complete a scoped engineering task. Inspect context first, list assumptions, request approval before risky actions, and return changed files plus verification.

## Review prompt
Review this Microsoft AutoGen workflow for permissions, state handling, prompt injection risk, observability, and deployment readiness. Return severity-ranked findings.

## Debug prompt
Debug this failed Microsoft AutoGen run. Inspect prompts, tool logs, state, traces, and final output. Identify the first bad decision and propose a regression check.

## Hardening prompt
Harden this Microsoft AutoGen setup for production by adding least-privilege permissions, approval gates, tests, monitoring, and rollback guidance.

## Prompt pattern notes
Specify each agent persona, allowed tools, collaboration protocol, turn budget, termination signal, and review responsibilities.
