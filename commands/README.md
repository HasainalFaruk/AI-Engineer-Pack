# Commands

## Purpose
The `commands` folder contains reusable task workflows for common AI-assisted engineering actions. Each command explains how to frame a request, what inputs matter, what outputs to expect, and which skills or frameworks pair well with the task.

## Contents
- [Build](build/README.md): implement a working feature, service, integration, or artifact.
- [Debug](debug/README.md): reproduce, diagnose, fix, and verify failures.
- [Deploy](deploy/README.md): prepare and validate safe releases.
- [Design](design/README.md): turn a problem into a technical approach with tradeoffs.
- [Document](document/README.md): create or update accurate maintainer and user documentation.
- [Learn](learn/README.md): explain code, concepts, systems, or workflows for a target learner.
- [Optimize](optimize/README.md): improve measured performance, cost, reliability, or workflow efficiency.
- [Refactor](refactor/README.md): improve internal structure while preserving behavior.
- [Review](review/README.md): evaluate changes for correctness, risk, tests, and maintainability.
- [Test](test/README.md): design, add, run, and interpret verification.

## Usage
Choose the command that matches the user's primary intent, then combine it with relevant [skills](../skills/README.md), [frameworks](../frameworks/README.md), [templates](../templates/README.md), and [checklists](../checklists/README.md). A good command prompt should include the goal, context, constraints, expected output, and verification standard.
